## 重构 GrandMA3 底部控制面板（组件化）

### 问题
用户反馈复刻的 MA3 UI 底部属性栏和编码器与原版相差很大。对比两张截图后确认了以下差距：
- 编码器太小（4个36px小旋钮 vs MA3的1个大编码器）
- 缺少左侧工具按钮列（Single Step / Align / Off / Readout / Natural）
- 中央布局完全不对
- 模式按钮缺少黄色高亮（Values and Timings）
- Grand Master 没有推子样式

### 方案
采用完全组件化重构，拆分为8个独立组件：

1. **AttributeTabBar** — 顶部属性标签栏（1 Sync, 2 Dimmer, 2 Position, 4 Color, 5 Beam, 6 Focus, Selection...）
2. **ToolButtonGroup** — 左侧工具按钮（Single Step, Align, Off, Readout, Natural）
3. **BigEncoderWheel** — 大编码器（92px直径，SVG精细刻度，3D凹陷效果，中心参数标签）
4. **EncoderResolutionBar** — 编码器分辨率（Coars, Fine, Incr, Nativ）
5. **ModeButtonBar** — 模式按钮（Values and Timings黄色高亮 + Phaser Overall/Steps + Absolute/Relative/Fade/Delay）
6. **ResolutionSelector** — Link Resolution / Single 下拉选择器
7. **ScreenSelector** — 屏幕选择器（Screen Y/X, Display, 箭头导航）
8. **GrandMaster** — Grand Master 推子（带填充条、手柄、刻度、百分比显示）

### 改动
- 新建 `packages/console/src/components/` 目录存放原子组件
- 重写 `ControlPanel.tsx` — 组合以上所有子组件
- 调整 `ConsoleShell.tsx` 底部高度 132px → 178px
- 所有组件支持受控/非受控两种模式，保留扩展接口

## 修正（第二轮）

### 用户反馈
1. Sync 不是属性，不需要
2. Align 和 Off 是一起的（Off 是 Align 的状态）
3. Readout 和 Natural 是一起的（Natural 是 Readout 的状态）
4. 编码器要靠左，不是居中

### 修正内容
- **AttributeTabBar**: 移除 Sync，属性从 1 Dimmer 开始
- **ToolButtonGroup**: 重构为带主子状态的结构
  - Align 按钮下方带 "Off" 子状态标签（可点击切换）
  - Readout 按钮下方带 "Natural" 子状态标签（可点击切换）
  - Single Step 保持独立
- **ControlPanel**: 布局改为 flex 从左到右排列，编码器靠左，中间用 `flex: 1` 占位把右侧推到最右

### 修正（第三轮）
- 用户指正：Align 的 Off 只是状态显示，点击 Align 按钮本身切换状态
- Align 状态循环：Off → < → > → >< → <> → (循环)
- Readout 状态循环：Natural → Percent → PercentFine → Physical → Decimal8 → Decimal16 → Decimal24 → Hex8 → Hex16 → Hex24 → (循环)
- 修正 ToolButtonGroup：带 states 的按钮点击按钮本身循环切换状态，下方只显示当前状态文字（不可点击）
- 按钮高亮逻辑：普通按钮 active，或状态按钮非第0状态时高亮

### 修正（第四轮）
